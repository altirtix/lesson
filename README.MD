# Solar System Landing Page

A responsive landing page introducing the planets and other highlights of our solar system. Built with Bootstrap 5.3.3 components and utility classes, with no custom CSS or additional libraries.

## View the page

Open `index.html` in a browser. An internet connection is needed to load Bootstrap from its CDN.

## Page sections

- Hero introduction and Sun facts
- Cards for all eight planets
- Expandable topics about moons, asteroids, comets, and the outer solar system
- Solar system quick facts
